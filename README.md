# BRG - Banner RGB Generator

Gerador moderno de texto com gradiente RGB para banners e assinaturas.

## Funcionalidades
- **Gradientes Dinâmicos**: Adicione quantas cores quiser.
- **Visualização em Tempo Real**: Veja o resultado conforme edita.
- **Responsivo**: Funciona em qualquer dispositivo.
- **Fácil de Copiar**: Código pronto para uso com um clique.

## Como usar
Abra o `index.html` no seu navegador.
