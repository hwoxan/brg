# Gradient Studio 🎨

Uma ferramenta profissional para criação de gradientes customizados em tempo real, focada em produtividade e design de alta fidelidade.

## 🚀 Funcionalidades

- **Renderização em Tempo Real:** Veja o resultado do seu gradiente enquanto digita.
- **Múltiplos Formatos de Saída:**
  - HTML (Span/Font)
  - BBCode (Fórum)
  - Minecraft (Hex MOTD)
  - Discord (ANSI)
- **Presets Vibrantes:** Alternância rápida entre paletas de cores profissionais.
- **Modos de Visualização:** Suporte para temas Dark/Light no preview.
- **Exportação:** Copie o código ou salve diretamente para o seu dispositivo.

## 🛠 Como usar

1. Abra o `index.html` em qualquer navegador.
2. Digite sua mensagem no campo "Mensagem do Banner".
3. Configure o número de nós de cor e ajuste a paleta.
4. Escolha o formato de saída e clique em "Copiar Código".

## 🛠 Stack Tecnológica

- **Frontend:** Tailwind CSS, JavaScript (Vanilla).
- **Design:** Focado em UX Enterprise/SaaS com interface glassmorphism.
