# Banner RGB Generator

Um gerador de texto com gradiente RGB moderno, rápido e standalone.

## 🔗 Acesse aqui:
[https://hwoxan.github.io/brg/](https://hwoxan.github.io/brg/)

## 📝 O que ele faz?
Este gerador permite criar textos estilizados com gradientes personalizados. Ideal para decorar nicks em jogos (Minecraft), perfis, mensagens (Discord, HTML) ou qualquer lugar que aceite formatação de cor.

### 🎨 Principais funcionalidades:
- **Gradientes RGB Customizáveis:** Escolha de 2 até 6 cores para o gradiente.
- **Paletas Predefinidas:** Inclui diversos presets prontos (Neon, Pôr do Sol, Floresta, Arco-íris, etc.).
- **Múltiplos Formatos:** Gere o código pronto para:
    - **HTML** (span com estilo)
    - **Minecraft** (códigos `§x` hex)
    - **Discord** (formato ANSI)
    - **BBCode**
    - **CSS** (`background-clip`)
    - **Raw Hex** (array)
- **Prévia em Tempo Real:** Veja o resultado antes de copiar.
- **Standalone:** Funciona totalmente no navegador, sem dependências ou conexões externas.
- **Design Moderno:** Interface responsiva, com suporte a temas e feedback visual ao copiar.
